# Security Policy

Do not publish exploitable details, meeting transcripts, personal data, or credentials in public issues or pull requests.

Use GitHub's Security tab and **Report a vulnerability** flow to send a private report when private vulnerability reporting is enabled. If unavailable, contact the repository owner privately through their GitHub profile and request a secure disclosure route. Do not disclose details publicly while arranging contact.

Include the affected version/commit, component, reproduction steps using synthetic notes, observed impact, and redacted logs. Never attach real customer transcripts, API keys, tokens, or provider headers.

Meeting Action Agent is an extraction assistant, not an authoritative record system. Treat model output as untrusted and have a human verify the original notes before relying on generated tasks or decisions.
